# mods

Mods for the editor inside ComfyUI: put `*.js` files here, or clone a repository of mods into a
folder here (`*.js` here and at the top of each folder load, in path order, when the editor opens;
a name starting with `_` or `.` is skipped). Reopen the editor after adding one. This folder's
contents are not committed, except this file. More mod folders can be named in `config.json`.

ComfyUI の中のエディタで使う MOD を置きます（`*.js`、または MOD のリポジトリを clone したフォルダ）。置いたらエディタを開き直してください。
MOD はエディタの中で自由に動くプログラムなので、信頼できるものだけを入れてください。
